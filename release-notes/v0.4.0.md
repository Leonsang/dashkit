# dashkit v0.4.0

## New: Tableau and Looker Studio, as dashkit's own plugins

Six new bundles, each also a plugin in dashkit's own Claude Code marketplace
(`claude plugin marketplace add leonsang/dashkit`). Claude Code and Copilot CLI install them through
their plugin manager, with their slash commands, subagents and hooks. Cursor, VS Code, Codex and
Gemini get the skills plus the MCP server, copied next to them and merged into each tool's MCP
config.

**Tableau Desktop 2026.3**
- **`tableau-authoring`**: the `tableu` MCP server, 21 tools over Desktop's External Client API
  (flag `ProjectAthena`), with an authoring skill, a `tableau-author` subagent and `/setup`. New in
  this release:
  - `.hyper` extracts for CSV/Excel sources (`datasource CreateExtract`), written with Tableau's
    Hyper API;
  - parameter and set actions;
  - navigation buttons;
  - `workbook ShowSheet`, to render a sheet that is not on screen.

  All of them were checked against Desktop's own validator and file loader.
- **`tableau-sdd`**: survey (Info + Lint), new, spec, tasks, build (each task in a transaction),
  verify (exported images and Desktop's warnings).
- **`tableau-guardrails`**: lints every `.twb`/`.twbx` the agent edits and blocks on errors.

**Looker Studio / Data Studio**
- **`looker-studio-authoring`**: the `looker-studio` MCP server, 34 tools over the editor through the
  browser (CDP), six best-practice skills, a `looker-studio-author` subagent and `/setup`. New in this
  release:
  - `copy_report` (Linking API), so work starts on a copy;
  - `add_source_field`, for source-level calculated fields: checkbox controls and preset filter
    buttons need a boolean one and now work end to end, verified in view mode;
  - components created from learned templates, verified.
- **`ls-sdd`**: survey (diagnose), a spec that becomes a declarative `.spec.json`, a build that dry-runs
  every apply first, verification in view mode.
- **`looker-studio-guardrails`**: lints every `*.spec.json` the agent edits, blocks on errors, and
  shows the dry-run plan when a browser is on the CDP port.

## `dashkit doctor`

New checks:
- uv;
- Tableau Desktop 2026.3+;
- the `ProjectAthena` flag, which it can fix with `tableu enable`;
- a browser on CDP port 9222.

Without `-b`, doctor checks the bundles you have installed.

## Fixed in the servers while moving them in

- **Tableau, live edits.** Desktop's live API silently drops new parameters, actions and buttons
  while answering SUCCEEDED. tableu now detects it (`applied: "partial"`) and `workbook Reopen`
  loads the change from the workbook file, after a backup.
- **Tableau, actions.** Actions are kept in the order the schema requires, so adding one to a
  workbook that already has actions no longer fails validation.
- **Looker Studio, new pages.** A new page was named by renaming the last page; the editor inserts
  it after the current one, so the wrong page got renamed.
- **Looker Studio, booleans.** The boolean data-type code was wrong (1 instead of 3).

## Enterprise

- Both servers build a `.mcpb` for Claude Desktop:
  - `npm run build:mcpb`: minified, with obfuscation proven safe for the browser-injected scripts;
  - `scripts/build_mcpb.py`: Nuitka-compiled, Windows.
- Internal research notes are never part of the repository or the bundles.
