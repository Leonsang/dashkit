# dashkit v0.2.1

## Fixed

- **The guardrail bundles now require `jq`.** data-goblin's hooks parse their input with jq and
  exit 0 when it is missing — no error, no warning, no validation. Found while testing on a clean
  Windows machine: `goblin-pbip` installed correctly and would have validated nothing. `dashkit
  doctor` now reports jq as required for `goblin-pbip` and `goblin-pbi-desktop`, and
  `--with-prereqs` installs it (`winget install jqlang.jq`, `brew install jq`, `apt-get install jq`).
  A test keeps every bundle that ships hooks from forgetting it again.
- The wizard says "1 change" and "1 skill" instead of "1 changes" and "1 skills".

## New

- `internal/tui/screens_test.go` renders every wizard screen, driven by the same keys a person
  presses, for documentation screenshots. Skipped unless `DASHKIT_SCREENS` is set.
